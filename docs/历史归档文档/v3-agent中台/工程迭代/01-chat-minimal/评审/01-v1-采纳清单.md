## 4. 后续人工复核重点

- 确认 `POST /api/chat/send` 的响应字段 `{ sessionId, runId, userMessageId, assistantMessageId }` 是否足够前端和 E2E 使用。
- 确认 `tool.call.*` 作为 conditional event 是否满足当前 L5 目标。
- 确认 `agent_session.status` 不表达 running 状态，而由 `agent_run.status` 和 session 互斥约束表达，是否符合后续 UI 预期。
- POC-1 执行完成后，必须回看四个 POC-1 `contract-notes.md` 的预填采纳表，不能直接沿用规划内容进入 Done。
